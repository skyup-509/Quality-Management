# 목적

- 센서 데이터를 활용하여 정상·불량 특성을 파악하고 주요 품질 변수를 탐색
- 민감도 분석을 통해 주요 변수를 선정하고 시뮬레이션으로 확장


# 순서

## 어떤 데이터로 품질을 판단할 수 있을까?

- JSON 형태의 센서 시계열 데이터를 파일 단위로 집계
- 온도, 습도, 진동, 가속도, 소음의 Mean·Std 생성
- 폴더명을 기준으로 정상(0)·불량(1) 분류

## 정상과 불량은 센서값에서 차이가 있을까?

- 정상·불량별 센서 분포 비교
- Mean과 Std의 차이 확인
- 불량과 관련된 센서 후보 탐색

## 센서값과 불량은 어떤 관계를 가질까?

- Logistic Regression을 활용한 변수별 관계 확인
- 변수의 영향 방향과 유의성 확인
- 선형적인 관계를 기준으로 변수 특성 파악

## 센서값을 변화시키면 불량 예측은 어떻게 달라질까?

- Random Forest를 활용해 비선형 관계 반영
- 센서의 Mean·Std를 변화시키며 불량 예측확률 변화 확인
- 변화율에 따른 민감도 곡선 및 결과 비교

## 어떤 변수를 다음 분석에 사용할까?

- 분석 결과, 평균값이 변동성보다 높은 민감도를 보임
- 소음·습도·진동·가속도의 평균값에서 상대적으로 큰 변화폭 확인
- 주요 변수를 선정하여 이후 시뮬레이션에 활용
