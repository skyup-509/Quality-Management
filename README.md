## 목적

생산 공정 데이터를 분석하여 불량에 영향을 미치는 주요 요인을 파악하고,

공정 조건 개선을 통한 불량률 감소 방안을 도출하는 것

## 순서

1. annotation 데이터 안의 공정 센서값 파악
2. 양품/불량품 공정 센서값 분포 EDA

   * 가설 ???
   * 정상 제품에서는 센서값이 일정 범위에 분포하고
   * 불량 제품에서는 각 센서값이 정상 범위의 상한을 넘어서는 경향이 나타남

$\\rightarrow$ 센서값이 높아질수록 불량 발생과 관련이 있을 가능성이 있다.

3. 이 센서가 실제로 불량 발생에 유의한 영향을 주는가?
* 방법론: 로지스틱 회귀 (Logistic Regression)
* 알고자 하는것: 센서값이 변화할 때 불량 발생 확률이 어떻게 변하는가?

< model.summary() 결과값 >

* 결과 해석:
1. 모든 센서 변수들의 p-value가 유의수준 0.05보다 작으므로, 다른 변수들을 함께 고려했을 때에도 각 센서 변수가 불량 발생과 통계적으로 유의한 관계를 보인다라고 할 수 있다.
2. 계수가 모두 양수이므로 해당 센서값이 증가할수록 불량 발생 확률이 증가한다.
* 결론: 모든 센서 변수가 불량 발생과 유의한 관계를 보이며, 센서값이 증가할수록 불량 발생 확률이 높아지는 경향을 확인하였다.
4. 개선하려면 무엇을 우선순위로 두고 조절하는 것이 중요한가?
* 가설: 모든 센서값을 똑같이 조절한다고 했을때 똑같이 개선되는 것은 아닐것이다.
