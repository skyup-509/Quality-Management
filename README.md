# SMT 공정 불량 원인 분석 및 품질 개선 방안 연구

## 배경
- 미납, 납부족, 납쇼트, 냉납 등의 불량 발생
- 제품 품질 저하 및 반복적인 리워크와 생산성 저하 유발 <-- 반복적인 리워크??

## 문제
- 어떤 요인이 불량 발생에 유의한 영향을 끼치는지 불명확
- 변화하는 공정 환경에서, 개별 요인의 영향과 불량률이 낮은 조건 확인 필요

## 분석

### Q1. 불량 데이터와 정상 데이터의 공정 환경에는 실제로 차이가 있는가?
- 연구 가설: 
	+ 불량과 정상 데이터의 온도, 습도, 진동, 가속도, 소음 수준에 차이가 있을 것이다
- 방법론: EDA (Exploratory Data Analysis)
	+ 정상/불량 데이터의 분포 및 평균 비교
	+ 온도, 습도, 진동, 가속도, 소음의 분포 시각화
- 결론: 
	+ 정상과 불량 데이터에서 공정 환경 센서값의 분포 차이가 확인되었다
	+ 온도 외의 센서에서 각 변수의 값이 정상 공정 환경의 상한을 넘는 것이 뚜렷하게 나타났다

### Q2. 어떤 공정 환경 요인이 불량 발생과 통계적으로 유의한 관계가 있는가?
- 연구 가설: 
	+ 모든 센서가 동일하게 영향을 미치지는 않을 것이며, 일부 센서의 평균 또는 변동성이 불량 발생과 유의한 관계를 가질 것이다
- 방법론:
	+ 로지스틱 회귀 분석 <-- 왜 이걸 썼지? 이 방법론의 특징은?
- 결론:
	+ 로지스틱 회귀 모형은 통계적으로 유의
	+ Q1에서 확인된 것처럼, 습도/진동/가속도/소음의 평균 및 표준편차는 불량 발생과 통계적으로 유의
	+ 온도를 제외한 나머지 변수에 대한 추가적인 분석 필요

### Q3. 머신러닝을 활용해 공정 환경에 따른 불량 발생 가능성을 시뮬레이션할 수 있는가?
- **검증 목적**: 
	+ 센서 데이터를 활용하여 학습한 머신러닝 모델은 정상과 불량을 높은 정확도로 분류할 수 있을 것이다
- 방법론:
	+ 로지스틱 회귀 분석
	+ Random Forest: Accuracy, F1-score, ROC-AUC를 이용한 모델 성능 확인
- 결론:
	+ 센서 데이터를 활용하여 정상과 불량을 높은 수준으로 분류할 수 있었다
	+ Random Forest에서 Accuracy 97.66%, F1-score 98.11%, ROC-AUC 98.25%를 기록했다
	+ 공정 환경 센서 데이터가 불량 상태를 구분하는 데 유용한 정보를 포함하고 있음을 확인

### Q4. 각 공정 환경 요인의 변화에 따라 불량 발생 가능성은 얼마나 달라지는가?
- 연구 가설: 
	+센서별로 불량 발생 가능성에 미치는 영향의 크기가 다를 것이다.
- 방법론:
	+ 민감도 분석: 각 센서 변수를 -30% ~ +30% 변화시키며 예상 평균 불량률 변화 확인
- 결론:
	+ 온도 외의 변수의 평균값에 대한 예상 불량률은 크게 변화
	+ 반면 표준편차는 유의하지 않은 영향
	+ 평균적인 공정 환경 수준이 주요 관리 대상이 될 수 있음을 확인

### Q5. 여러 공정 환경 조건을 조합했을 때 불량 발생 가능성이 낮은 조건을 찾을 수 있는가?
- 연구 가설:	
	+ 개별 센서의 영향뿐만 아니라 여러 센서의 조합에 따라 불량률이 달라질 것이며, 상대적으로 불량률이 낮은 조건을 도출할 수 있을 것이다
- 방법론
	+ 온도를 제외한 공정 환경의 값을 **Low / Mid / High**로 구간화 $\rightarrow$ 총 81개의 조건 생성
	+ Random Forest를 통해 각 조건의 예상 불량률 비교
- 결론:
	+ 각 변수 조합을 통한 가장 낮은 불량률은 1.67%로 개선될 것으로 예상된다
	
		`소음: 68.893 | 습도 45.902 | 진동 0.3766 | 가속도 0.0277`
